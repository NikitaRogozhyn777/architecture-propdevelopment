## 2. Определение ролей и групп пользователей

| Роль               | Права роли                                      | Группы пользователей                     |
|--------------------|------------------------------------------------|------------------------------------------|
| **cluster-admin** (существует по умолчанию)  | Полный доступ ко всем ресурсам (* в verbs)     | DevOps, SRE                              |
| **namespace-admin**| Полный доступ в рамках своего namespace (create, delete, patch) | Продуктовые команды (разработчики)      |
| **namespace-viewer**| Только чтение (get, list, watch)              | Менеджеры, аналитики                     |
| **security-auditor**| Чтение + доступ к секретам (get, list для secrets) | Специалист по ИБ                       |
